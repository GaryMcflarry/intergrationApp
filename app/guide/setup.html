AstrumSetup guides

Install and open Astrum, then choose Set up in the app or its tray menu. Enter your account details in the setup window Astrum opens on your computer.

Spotify YouTube Discord

Spotify

  1. Create an app in the Spotify developer dashboard and select Web API.
  2. Add http://127.0.0.1:43210/spotify/callback to the app’s Redirect URIs. In User Management, make sure your Spotify account has access.
  3. In Astrum’s Spotify setup, enter the Client ID and choose Connect Spotify. Playback controls require Spotify Premium.

YouTube

You can watch a video by pasting its link into Astrum. Connect Google for search, playlists, and liked videos.

  1. Create a Google Cloud project and enable YouTube Data API v3.
  2. In Google Auth Platform, set up the consent screen and add your account as a test user if the app is in testing.
  3. Create a Web application OAuth client with http://localhost:43210 as an authorized JavaScript origin. Enter the Client ID in Astrum’s YouTube setup and sign in.

Discord

  1. Create an application in the Discord developer portal. Enter its Application ID in Astrum’s Discord setup to enable Rich Presence.
  2. To read selected channels, add a bot, enable Message Content Intent, and invite it to your server. Enter the bot token only in the local setup window.
  3. To share tracks, create a channel webhook in Discord and paste its URL into the local setup window.
